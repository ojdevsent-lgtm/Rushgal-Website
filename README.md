# Rushgal Website

Client-ready fashion website concept for Rushgal, built mobile-first for a Lagos audience.

## Stack
- Semantic HTML
- CSS with responsive layout and design tokens
- Vanilla JavaScript
- No framework or build step
- Netlify-ready static deployment

## Current direction
Editorial, restrained and trustworthy rather than template-like. The site prioritises product discovery, direct WhatsApp enquiries, location and brand credibility.

## Before production launch
- Replace concept photography with Rushgal-owned photography.
- Confirm collection names, prices, delivery policy, returns policy and social links with the client.
- Connect the final domain.
- Add analytics and Search Console after approval.
